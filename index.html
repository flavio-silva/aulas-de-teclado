Teclado para a igreja

Aulas de teclado

Do zero até tocar “Sonda-me, Usa-me” (Aline Barros), uma lição curta de cada vez.

Lições

  1. O mapa do teclado: encontre o Dó ~15 min
  2. Seu primeiro acorde: C ~15 min
  3. Mais dois acordes: F e G ~20 min
  4. O acorde Am, menor (em breve)

Referência

  • Mapa do teclado para imprimir
  • Acordes para imprimir

Não precisa de teclado de verdade para começar: cada lição tem um teclado virtual com som. Funciona no computador, no tablet e no celular.
