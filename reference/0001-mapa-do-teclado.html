Mapa do teclado

A regra de ouro

Dó = tecla branca à esquerda das 2 pretas.
Fá = tecla branca à esquerda das 3 pretas.

Nomes e cifras

NomeDóRéMiFáSolLáSi
CifraCDEFGAB

Macete: o alfabeto começa no Lá (A = Lá, B = Si, C = Dó…). Depois do Si, recomeça no Dó, mais fino.

Primeiro acorde

C (acorde de Dó) = Dó + Mi + Sol: uma branca sim, uma não. É o primeiro acorde de “Sonda-me, Usa-me”.
